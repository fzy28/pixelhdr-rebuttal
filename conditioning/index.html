Setup

All variants use the same backbone (HiDream-O1-Image, 8B), the same fine-tuning data and the same 2048² resolution, with similar training compute (about 400 GPU-hours each). They differ only in whether the target lighting keeps the two pretrained image-conditioning pathways of the base model.

    Internal synthetic benchmark (170 held-out pairs), same protocol as our ablations. On this in-distribution benchmark, all variants except channel concatenation give reasonable results, although none reaches the pretrained pathways. Channel concatenation is much worse even here. A possible reason is that this design was developed for latent diffusion models, whose architecture differs from our pixel-space backbone, so it should not simply be copied to it.
